The reply brings the maintainer the questions from a cold read of the draft, most important first, and separates the ones the draft or code already answers or that are minor from the ones the maintainer must decide. Saying the draft is not ready, can't start as written, has vague steps, or must wait for another release or for the maintainer's answers is what the cold read is for and is not a reason to fail. Answer FAIL if it gives no questions from the cold read, answers a maintainer's question itself (such as which CSV column to read), says the plan was accepted or the plan file was written, or says the draft must gain a Review Focus or Interfaces section before it can be used.
